Explaining Functions


This section formalizes what a function truly is in mathematics. It explains that a function is not just a tool or a machine, but a precise relationship between two sets of values. It establishes the rule that for every valid input, there must be exactly one corresponding output, ensuring consistency and predictability in mathematical relationships.

Key Definitions

  • Function: It is defined as a rule where each input has exactly one output. This means no single value of x can produce two different values of y.
  • Notation: f(x) = y is read as "f of x equals y". This notation tells us that y depends on the value of x, making it clear which variable is the input and which is the output.
  • Domain: This refers to the set of all possible input values (x-values) that are allowed to be used in the function.
  • Range: This refers to the set of all possible output values (y-values) that result from applying the rule.
